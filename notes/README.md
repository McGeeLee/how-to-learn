## 怎样使用这些笔记

每篇笔记分别记录核心问题、理论机制、代表性证据、适用条件和个人学习启发。建议同时打开对应原书章节，检查论证与研究细节。

- **作者结论：**书中作者对理论或研究的解释，不自动视为已经得到一致支持。
- **研究证据：**记录本章转述的参与者、任务、比较条件与结果；提及的原论文尚未逐篇独立复核，个别回查原论文的情况另行注明。
- **个人学习启发：**由笔记整理者提出的应用推论，不冒充本章实验直接验证的方案。
- **页码：**同时标明印刷页和用户提供PDF的文件页，便于回查；文件页偏移只适用于这两份PDF。

本轮笔记依据2015和2019年的书中内容整理，未系统检索出版后的研究。扫描文字识别中，表格偶有错序；保留可核对的正文信息，对无法可靠确认的数字不作精确转述。笔记是选择重点的原创概括，适合用作阅读导航。
