# 如何学习

从认知心理学、教育心理学和学习科学的学术研究出发，理解学习机制，评估学习方法，并整理自己的阅读笔记。

## 从哪里开始

[学术书目与阅读建议](reading-list.md)收录五本已核验官方书目信息的教材、研究专著与研究综述。

如果主要关心具体学习方法，可以先读 Fiorella 与 Mayer 的 *Learning as a Generative Activity*，再按问题查阅 *The Cambridge Handbook of Cognition and Education*。

如果希望先建立记忆机制的基础，可以从 Baddeley、Eysenck 与 Anderson 的 *Memory* 第4版开始。

## 研究范围

- 记忆的编码、提取和遗忘
- 自测、分散练习与交错练习
- 概念理解、自我解释与知识迁移
- 元认知、理解监控与自我调节学习
- 学习材料、既有知识和学习情境对方法效果的影响

## 整理原则

1. 记录可追溯的原始研究、教材章节或研究综述。
2. 阅读结论时，同时记录研究对象、任务、对照条件和测量指标。
3. 区分作者的证据、自己的解释，以及尚待检验的应用想法。
4. 对学习方法说明适用条件和研究局限。
5. 保留书目和官方链接；笔记使用自己的表述。
